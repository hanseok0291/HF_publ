헥토파이낸셜 주식회사(이하 "헥토파이낸셜")는 고객(이하 "고객")의 개인정보를 중요시하며 개인정보 보호법, 정보통신망 이용촉진 및 정보보호 등에 관한 법률 등 관계법령을 준수하고 있습니다. "고객"은 개인정보처리방침을 통하여 "헥토파이낸셜"의 개인정보가 어떠한 용도와 방식으로 이용되고 있으며 개인정보보호를 위해 어떠한 조치가 취해지고 있는지 알려드립니다.

 

수집·이용 목적 수집하는 개인정보의 항목 개인정보 보유 및 이용기간
출금동의 내역 조회 간편현금결제 : 거래은행, 계좌번호, 휴대폰번호 목적 달성 후 즉시 파기
내통장결제 : 거래은행, 계좌번호, 휴대폰번호
결제내역 조회 및 거래명세표 출력 간편현금결제 : 거래은행, 계좌번호, 휴대폰번호
내통장결제 : 거래은행, 계좌번호, 휴대폰번호, 생년월일
휴대폰결제 : 휴대폰번호, 주민번호 앞 7자리
신용카드 : 카드번호, 승인번호, 구매자명
실시간 계좌이체 : 거래은행, 계좌번호 뒤 5자리
가상계좌 : 거래은행, 가상계좌번호
문화상품권 : 컬쳐랜드 ID
해피머니 : 해피머니 ID
도서문화상품권 : 도서문화상품권 ID
스마트문상 : 스마트문상 PIN
틴캐시 : 틴캐시 ID, 틴캐시 PIN

 

* 위의 개인정보 수집·이용 동의를 거부할 수 있습니다. 단, 동의를 거부하는 경우 조회가 정상적으로 완료될 수 없음을 알려드립니다.
