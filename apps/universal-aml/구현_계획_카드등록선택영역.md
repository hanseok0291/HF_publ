# 카드 등록 선택 영역 구조 분석 및 구현 계획

## 1. 현재 상태 분석

### 1.1 현재 코드 구조 (`indexReg.html`)

```html
<!-- 헤더 -->
<header class="header">
  <h1 class="brand-name">카드 사용/수령 등록</h1>
  <button class="btn-back btn"></button>
  <!-- 닫기 버튼 없음 -->
</header>

<!-- 선택 영역 -->
<ul class="sub-title-list">
  <li>
    <a href="#">
      카드 사용 등록
      <span class="sub-tit">모바일로 발급 후, 대리인이 수령 하셨나요?</span>
    </a>
  </li>
  <li>
    <a href="#">
      카드 수령 등록
      <span class="sub-tit">가맹점에서 직접 수령하셨나요?</span>
    </a>
  </li>
</ul>
<!-- 카드 등록 안내 링크 없음 -->
```

### 1.2 현재 스타일 (`card.css`)

- `.sub-title-list`: 세로 정렬 리스트, 10px 간격
- `.sub-tit`: 설명 텍스트 (16px, #929292)
- `::after`: 오른쪽 화살표 아이콘
- 아이콘 없음, 배경색 없음

## 2. Figma 디자인 요구사항

### 2.1 헤더
- **제목**: "카드 등록" (현재: "카드 사용/수령 등록")
- **뒤로가기 버튼**: 유지
- **닫기 버튼**: 추가 필요 (우측 상단 X 아이콘)

### 2.2 선택 카드 영역
- **카드 사용 등록**
  - 왼쪽: 카드 아이콘 (카드/결제 아이콘)
  - 중앙: "카드 사용 등록" 텍스트
  - 오른쪽: 화살표 아이콘
  - 배경: 밝은 회색 (#F7F7F8 또는 유사)
  - 설명 텍스트 제거

- **카드 수령 등록**
  - 왼쪽: 박스/패키지 아이콘
  - 중앙: "카드 수령 등록" 텍스트
  - 오른쪽: 화살표 아이콘
  - 배경: 밝은 회색 (#F7F7F8 또는 유사)
  - 설명 텍스트 제거

### 2.3 하단 안내 링크
- **"카드 등록 안내"** 링크 추가
- 중앙 정렬
- 회색 텍스트 (#929292 또는 유사)
- 클릭 시 안내 모달/페이지로 이동
