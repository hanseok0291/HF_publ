## 🎨 상세 내용 제안

### 1. 이미지 추출 최적화

**현재 상황**:
- Figma에서 수동으로 3배수 이미지 추출
- 이미지 추출 시간: 약 5분/페이지
- 추출 후 경로 수동 매핑 필요

**개선 방안**:
- Figma Export 설정 템플릿 생성
- MCP 설정 개선으로 자동 3배수 추출
- 이미지 경로 자동 매핑 강화

**예상 효과**:
- 이미지 추출 시간: 5분 → 1분 (80% 감소)
- 수동 작업 시간 대폭 감소

---

### 2. 상세 간격 조정 (.cursorrules 디테일 강화)

**현재 상황**:
- 기본 구조와 간격만 자동 적용
- 디자인과 다른 상세 간격은 수동 조정 필요
- 일부 섹션 간격이 디자인과 다름

**개선 방안**:
- `.cursorrules`에 상세 간격 규칙 추가
  - 섹션별 기본 간격 정의
  - 요소별 간격 규칙 명시
  - 디자인 시스템 기반 간격 규칙
- 디자인 시스템 토큰 활용

**예상 효과**:
- 수동 간격 조정 시간 감소
- 디자인 일치도 향상
- 코드 일관성 향상

**구체적 예시**:
```css
/* .cursorrules에 추가할 내용 예시 */
- 섹션 간 기본 간격: 30px
- 카드 내부 간격: 16px
- 버튼 간 간격: 12px
- 텍스트 간 간격: 8px
```

---

### 3. 차후 다른 프로젝트에도 적용

**현재 상황**:
- 전용통장 프로젝트에만 적용
- 프로젝트별 특성에 맞는 규칙 필요

**개선 방안**:
- 프로젝트별 `.cursorrules` 템플릿 생성
- 공통 규칙과 프로젝트별 규칙 분리
- 팀 내 공유 및 교육 진행
- 다른 프로젝트에 단계적 확대

**예상 효과**:
- 전사 생산성 향상
- 코드 일관성 전사 확대
- 팀 전체 워크플로우 개선

**적용 계획**:
1. **1단계**: 유사 프로젝트 2-3개 적용
2. **2단계**: 피드백 수집 및 개선
3. **3단계**: 전사 확대 검토
