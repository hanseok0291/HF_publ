현금영수증 API 소개

현금영수증 실시간 API 발급을 위한 문서입니다.

현금영수증 API 연동규격서

1. 개요

1.1 현금영수증 등록/조회

  1. 현금영수증 등록/취소 호출, 승인번호와 현금영수증 발급일자 수신 (가맹점 → 세틀뱅크)
  2. 익일(D+1) 00시 전일 요청한 현금영수증 발급내역을 국세청으로 일괄 파일 송신 (세틀뱅크 → 국세청)
  3. D+1일 9시-12시, 현금영수증 등록 오류내역을 국세청으로부터 수신 (국세청 → 세틀뱅크)
  4. 13시 이후, 현금영수증 발급 오류내역 조회

※ 국세청 작업에 의해, 오류내역 조회 가능 시간은 지연될 수 있습니다.

1.2 현금영수증 재처리

1. 현금영수증 등록/취소 호출, 승인번호와 현금영수증 발급일자 수신 (가맹점 → 세틀뱅크)

2. 익일(D+1) 00시 전일 요청한 현금영수증 발급내역을 국세청으로 일괄 파일 송신(세틀뱅크 → 국세청)

3. 9시-12시, 현금영수증 등록 오류내역을 국세청으로부터 수신 (국세청 → 세틀뱅크)

4.1. 자동재처리 가맹점인 경우
4.1.1. 13시 이후, 현금영수증 발급 오류내역 조회 (재처리 데이터는 세틀뱅크에서 자동 생성되어, 익일 국세청으로 일괄 전송함)

4.2. 자동재처리 가맹점이 아닌 경우
4.2.1. 13시 이후, 현금영수증 발급 오류내역 조회
4.2.2. 조회된 오류내역 중 재처리 요청 대상 건을 재처리 API를 통해 등록 진행

5. D+2 전일 재처리 요청된 거래내역을 국세청으로 일괄 전송 (세틀뱅크 → 국세청)

6. 현금영수증 등록 오류내역을 국세청으로부터 수신 (국세청 → 세틀뱅크)

7. 재처리 결과내역 API를 통해 재처리 결과 수신

※ 국세청 작업에 의해, 오류/재처리 내역 조회 가능 시간은 지연될 수 있습니다.

3. 현금영수증 등록 / 조회

3.1 현금영수증 등록/취소

 

3.1.1 URL

https://{domain}/pgtrans/CashReceiptMultiAction.do?_method=insertReceiptInfo

 

3.1.2 등록요청 parameter

필드 데이터타입 길이 필수 필드명
mid String 10 ● 상점아이디
assort String 1 ● 승인구분 (‘0’)
transNo String 50 ● 승인주문번호 (가맹점 고유번호)
ordNm String 30 ○ 주문자명
trDt String 14 ● 거래일시 (yyyyMMddhh24miss)
taxYn String 1 ○ 과세구분
amt Number 10 ● 공급가액
vat Number 10 ●
svcAmt Number 10 ○ 봉사료
bizRegNo Number 10 ○ 하위사업자번호
purpose String 1 ● 용도구분
identityGb String 1 ● 현금영수증 등록번호 구분
identity Number 18 ● 현금영수증 등록번호
deductionType String 1 ○ 추가공제 구분 (대중교통/도서,공연비)

 

3.1.3 취소요청 parameter

필드 데이터타입 길이 필수 필드명
mid String 10 ● 상점아이디
assort String 1 ● 승인구분 (‘1’)
transNo String 50 ● 취소주문번호 (가맹점 고유번호)
ordNm String 30 ○ 주문자명
trDt String 14 ● 취소거래일시 (yyyyMMddhh24miss)
taxYn String 1 ○ 과세구분
amt Number 10 ● 공급가액
vat Number 10 ● 부가세
svcAmt Number 10 ○ 봉사료
bizRegNo Number 10 ○ 하위사업자번호
purpose String 1 ● 용도구분
identityGb String 1 ● 현금영수증 등록번호 구분
identity Number 18 ● 현금영수증 등록번호
deductionType String 1 ○ 추가공제 구분 (대중교통/도서,공연비)
authNo String 9 ● 원거래 승인번호
orgTrDt String 14 ● 원거래 승인일시 (yyyyMMddhh24miss)

 

3.1.4 등록/취소 요청 parameter 상세설명

필드 상세내용
mid 당사로부터 발급받은 가맹점ID
assort 승인구분 (승인 : 0 / 취소 : 1)
transNo 가맹점에서 관리하는 고유주문번호
취소주문번호는 승인주문번호가 아닌, 새로 채번된 주문번호로 요청하셔야 합니다.
taxYn 과세구분 (과세 : N / 면세 : Y / 복합과세 : G)
* 과세(N) – amt 과세금액, vat 부가세 입력
* 면세(Y) – amt 면세금액, vat는 0으로 입력
* 복합과세(G) – amt (과세+면세금액), vat는 과세금액의 부가세를 입력
* 미 입력(null) – amt에 거래금액 입력
(taxYn 미 요청 시, 과세구분 값을 당사 등록된 가맹점 정보 기준으로 구분하여, amt금액에서 자동 계산합니다.)
* 전체 취소 시 identityGb, identity 빈 값으로 전달 시에는 원거래승인번호, 원거래승인일시의 현금영수증 발행 정보로 취소
* 부분 취소 시에는 identityGb, identity 빈 값으로 전달하고 취소 금액에 대해 계산 후 전달
* 취소 시에 현금영수증 등록번호구분, 현금영수증 등록번호, 과세구분, 공급가액, 부가세, 봉사료, 하위사업자번호, 용도구분은 요청주시는대로 국세청에 신고가 되게 되니 원거래 조회 후 취소를 할 수 있는 기준인 identityGb, identity 빈 값으로 전달 권장합니다.
purpose 용도구분 (0 : 소득공제 / 1 : 지출증빙)
* 자진발급번호로 요청 시, 0 (소득공제)로 입력
identityGb 현금영수증 등록번호 구분
1 : 카드번호 (국세청에 등록된 카드번호)
2 : 주민번호
3 : 사업자번호
4 : 휴대전화번호
* 자진발급번호로 요청 시, 4 (휴대전화번호)로 입력
identity identityGb의 구분값에 따른 등록번호
* 숫자로 입력
* 자진발급번호로 요청 시, ‘0100001234’ 로 입력.
deductionType 대중교통 및 도서·공연비인 경우에만 요청 (대중교통 : Y / 도서,공연비 : C)
* 도서·공연비 소득공제 제공 단일사업자인 경우, 값을 전송하지 않아도 도서·공연비로 발급 처리됨.

3.2 현금영수증 발급오류내역 조회 API

 

3.2.1 URL

https://{domain}/pgtrans/CashReceiptMultiAction.do?_method=getReceiptErrList

 

3.2.2 조회 요청 parameter

필드 데이터타입 길이 필수 필드명
mid String 10 ● 상점아이디
trDtGb String 1 ● 거래일자 조회구분
trDt1 String 8 ● 조회시작일자 (from)
trDt2 String 8 ○ 조회종료일자 (to)
ordNo String 40 ○
authNo String 9 ○

오류내역 조회

  • 오류내역은 등록요청일자 기준 익일부터 조회 가능합니다.(13시 이후 조회)
    국세청 작업으로 인해 늦어지는 경우 조회결과 확인이 늦어질 수 있습니다. (조회불가 시, 2001 오류코드 응답)
  • 해당 API는 재처리 건에 대한 오류내역은 조회되지 않습니다.
    재처리 발급건의 결과내역은 "4.2 현금영수증 재처리 결과내역 조회 API" 바로가기 를 참고하시기 바랍니다.

 

3.2.3 요청 parameter 상세설명

필드 상세내용
trDtGb 조회일자 기준
1 : 등록 시 요청한 trDt 값 기준일자로 조회 (취소 시 취소 API 요청일자)
2 : 국세청 전송일자 기준으로 조회
* 국세청 전송일자 : API요청일의 익일 (국세청 작업 시, 변동될 수 있습니다.)
trDt1 조회 시작일자 (yyyyMMdd)
trDt2 기간 조회 시 종료일자 (yyyyMMdd)
* 조회기간은 최대 7일까지 가능합니다.
* 일일 데이터만 조회 시 빈 값으로 요청 (빈 값으로 요청 시 trDt1 날짜 기준으로 조회됩니다.)

4. 현금영수증 재처리 등록 / 조회

현금영수증 재처리는 국세청 발급 오류 건에 한하여 재처리 되고, 가맹점의 동의여부에 따라 자동 재처리 가능합니다.
(자동 재처리 신청은 영업담당자를 통해 문의)

 

자동 재처리 가맹점인 경우

  1. 국세청 오류코드에 따라 당사에서 일괄 자동 재처리됩니다.
  2. 자동 재처리 결과는 재처리 내역조회 API를 통해 확인 가능하며 재처리 불가한 오류코드는 가맹점 확인이 필요한 건으로, 필요한 경우 재처리 등록 API를 호출해주시기 바랍니다.
  3. 자동 재처리 시 등록번호는 자진발급번호로 등록, 취소건 재처리는 원승인거래 등록번호로 발급됩니다.
    자진발급 번호로 발급받은 거래 건은 고객이 국세청(홈텍스) 홈페이지에서 변경 등록합니다.
  4. 자동 재처리 건의 승인번호 부여 기준
    발급일자가 국세청 등록 가능 기한(영업일 기준 3일전) 이내 거래인 경우 최초 발급된 승인번호와 동일한 번호 및 발급일자로 재처리 되고, 기한 초과한 거래 건은 승인번호와 발급일자가 신규 채번됩니다.
    API를 통해 재처리 요청하신 거래는 영업일 기준에 관계없이 승인번호와 발급일자 값이 신규 채번됩니다.

 

자동 재처리 가맹점이 아닌 경우

  2. API를 통해 재처리 요청하신 거래는 영업일 기준에 관계없이 승인번호와 발급일자 값이 신규 채번됩니다.

4.2.3 조회 요청 parameter 상세설명

필드 상세내용

searGb 값 기준,
1, 2 : 재처리 건의 원거래 발급일자로 요청
