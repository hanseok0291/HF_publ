## 🎯 POC 개요

### 목적
Figma MCP(Model Context Protocol)를 활용한 AI 기반 퍼블리싱 워크플로우 검증

### 범위
- **프로젝트**: 전용통장 (dedicatedSavings)
- **페이지 수**: 4개 페이지
- **기간**: [작업 기간 입력]
- **도구**: Figma Desktop App + Cursor AI + MCP Server

### 핵심 가설
1. Figma 디자인을 AI가 자동으로 코드로 변환할 수 있는가?
2. 프로젝트 표준과 가이드라인을 준수하는 코드가 생성되는가?
3. 기존 수동 작업 대비 생산성 향상이 있는가?


### 작업 프로세스

#### 1단계: Figma 디자인 선택
- Figma Desktop App에서 컴포넌트/프레임 선택
- MCP를 통해 디자인 컨텍스트 추출

#### 2단계: AI 코드 생성
- Cursor AI가 Figma 디자인 분석
- `.cursorrules` 기반 프로젝트 표준 적용
- HTML/CSS 자동 생성

#### 3단계: 수정 및 보완
- 이미지 경로 수정 (로컬 경로로 변경)
- 프로젝트 표준 미준수 부분 수정
- 인터랙션 및 애니메이션 추가

- **CSS 스타일링**: 2시간
- **이미지 추출 및 최적화**: 30분
- **반응형 대응**: 1시간

3. HTML 마크업 작성
4. CSS 스타일링 (픽셀 단위 매칭)
5. 이미지 수동 추출 및 경로 설정
6. 반복적인 수정 작업

### After (Figma MCP 활용)

#### 작업 시간 추정
- **Figma 컴포넌트 선택**: 1분
- **AI 코드 생성**: 2분
- **이미지 경로 수정**: 5분

- **인터랙션 추가**: 15분
- **최종 검수**: 10분
- **총 소요 시간**: 약 43분/페이지

#### 작업 방식
1. Figma에서 컴포넌트 선택
2. AI에게 "선택한 컴포넌트 구현해줘" 요청
3. 자동 생성된 코드 검토
4. 프로젝트 표준 미준수 부분 수정 요청
5. 인터랙션 및 추가 기능 요청

## 🔧 개선 사항

### 1. 이미지 처리 자동화
**현재 문제점**
- Figma MCP가 이미지를 자동으로 3x 해상도로 추출하지 못함
- 수동으로 Figma에서 3x로 추출 필요

**개선 방안**
- Figma MCP 설정에서 기본 해상도 3x로 설정
- 또는 이미지 추출 스크립트 자동화

### 2. 프로젝트 표준 자동 적용
**현재 상태**
- `.cursorrules`에 표준 정의되어 있음
- 대부분 자동 적용되나 일부 수동 수정 필요

**개선 방안**
- `.cursorrules` 규칙 강화
- 자동 검수 체크리스트 추가

### 3. 상태바 자동 제거
**현재 문제점**
- Figma 디자인에 iOS 상태바 포함 시 수동 제거 필요

**개선 방안**
- `.cursorrules`에 상태바 제거 규칙 명시 (✅ 완료)
- AI가 자동으로 상태바 영역 인식 및 제거

### 4. 반응형 대응
**현재 상태**
- 기본 반응형 코드 생성
- 일부 미디어 쿼리 수동 추가 필요

**개선 방안**
- 반응형 규칙 `.cursorrules`에 추가
- 자동 미디어 쿼리 생성
