Button

버튼은 사용성에 따라 Component Type이 구분되고, 유저의 행동을 유도하거나 원하는 선택을 할 수 있도록 합니다. 이 가이드는 docs/components/button-spec.md를 기준으로 합니다.

기본 원칙

태그 규칙 버튼 동작은 <button>, 페이지 이동은 <a>를 사용합니다. div/span으로 버튼처럼 보이게 하지 않습니다.

구성 요소 버튼 컨테이너, 라벨(btn__label), 좌측/우측 아이콘(선택). 라벨은 <span class="btn__label">로 감싸고, 아이콘은 icon-spec.md 기준을 따릅니다.

클래스 구조

구분 클래스
기본 btn
Variant btn--primary btn--secondary btn--tertiary
Size btn--large btn--medium btn--small btn--xsmall btn--xxsmall
내부 요소 btn__label
<button type="button" class="btn btn--primary btn--large">
  <span class="btn__label">Label</span>
</button>

사용 원칙

  • Primary — 한 영역의 주요 행동, 대표 CTA
  • Secondary — 보조 행동, 취소/옵션/부가 액션
  • Tertiary — 부가적인 행동, 더보기/자세히/덜 강조된 선택지
  • Size — large: 메인 액션 / medium: 일반 / small: 카드·리스트 / xsmall·xxsmall: 제한된 영역. 높이는 size별 고정값, 좌우 padding만 사용
  • Icon — left: 추가·생성·검색·다운로드 / right: 다음·이동·상세보기

하지 말아야 하는 것

  • 버튼처럼 보이는 div 사용
  • 정의되지 않은 variant·size 생성
  • 아이콘에 직접 클릭 이벤트 연결
  • disabled를 시각적으로만 처리하고 속성 누락
  • 동일 역할 버튼을 페이지마다 다른 HTML 구조로 생성
  • 상하 padding으로 버튼 높이를 조절하는 방식 사용

접근성

버튼은 <button> 또는 목적에 맞는 <a>를 사용합니다. 장식용 아이콘은 aria-hidden="true", 아이콘만 있는 버튼은 aria-label을 제공합니다.

<button type="button" class="btn btn--secondary btn--medium" aria-label="닫기">
  <i class="ico ico-close" aria-hidden="true"></i>
</button>

Button Group

아래 콘텐츠가 있을 경우 박스 버튼 컴포넌트와 조합하여 사용합니다. 버튼 개수·배치·비율·서브 텍스트 유무에 따라 여러 패턴을 사용할 수 있습니다.

Btn=1, Horizontal, Sub-Text=False
Btn=1, Horizontal, Sub-Text=True

약관 및 정보 제공 등에 동의합니다.

Btn=2, Vertical
Label
Btn=2, Horizontal, Ratio=1:1
Btn=2, Horizontal, Ratio=4:6
Btn=2, Horizontal, Icon=true, Sub-Icon_btn=True
Btn=3, Horizontal, Icon=true, Sub-Icon_btn=True

  <button type="button" class="btn btn--primary btn--large"><span class="btn__label">Label</span></button>
