Chip

칩(Chips)은 사용자로 하여금 정보, 선택, 콘텐츠의 필터링, 그리고 특정 액션을 유도합니다.

이 가이드는 Figma Chip 레이어를 참고하여 Chips-basic과 Chips-option 패턴을 정의합니다. 레이아웃은 웹 가이드에 맞게 단순화했습니다.

Chips-basic

Chips-basic은 리스트를 필터링하는 용도로 사용합니다. Figma의 Chips-basic / Primary 컴포넌트를 기준으로, default / icon 타입과 on/off 상태를 사용합니다.

Chips-basic / Primary — default & icon (on / off)

Chips-basic / Sub — default & icon (on / off)

Chips-option

Chips-option은 다수의 선택지 중 하나를 선택할 때 사용합니다. 선택된 칩은 상태가 유지되며, 현재 페이지나 콘텐츠의 모드를 전환하는 데 사용됩니다.

Chips-option — 상태 (default / active / disabled)

스크롤 & Fixed 아이콘 패턴

칩 리스트가 가로 폭을 넘어갈 경우, 가로 스크롤로 노출합니다. 좌측에 고정(Fixed)되는 필터 아이콘 칩을 둘 수 있으며, 이 경우 배경 그라데이션으로 스크롤 가능 범위를 암시합니다.

가로로 스크롤하여 더 많은 칩을 확인할 수 있습니다.
