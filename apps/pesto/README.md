# Pesto Project

This folder contains two deliverables:

- `landing`: Static HTML landing pages.
- `checkout`: React-based payment window.

## Quick Start

### Landing

Open `landing/index.html` in a browser or serve with a static server.

### Checkout

```bash
cd checkout
npm install
npm run dev
```

## Folder Layout

- `landing/` static pages and assets
- `checkout/` React app for payment flow
- `shared/` shared tokens and utilities
- `docs/` project documentation
