# Figma MCP 데모 시연 스크립트

## 🎯 데모 목표
Figma MCP를 활용한 AI 기반 퍼블리싱 워크플로우를 시연하여 생산성 향상을 입증

---

## 📋 사전 준비

### 필수 준비물
- [ ] Figma Desktop App 실행
- [ ] Cursor AI 실행
- [ ] 브라우저 개발자 도구 준비
- [ ] 스크린 공유 설정
- [ ] 예제 Figma 파일 열기

### 예제 파일
- 전용통장 프로젝트 Figma 파일
- 또는 간단한 컴포넌트 프레임

---

## 🎬 시나리오 1: 간단한 페이지 생성 (5분)

### Step 1: 상황 설정 (30초)
```
"먼저 간단한 페이지 생성 과정을 보여드리겠습니다.
디자이너가 Figma에서 페이지를 완성했고,
이제 이를 코드로 구현해야 하는 상황입니다."
```

### Step 2: Figma에서 컴포넌트 선택 (30초)
```
[Figma Desktop App 화면]
"Figma에서 전용통장 사전알림 페이지 프레임을 선택하겠습니다.
이 프레임에는 헤더, 히어로 섹션, 혜택 섹션 등이 포함되어 있습니다."
```

**액션**:
1. Figma에서 프레임 선택
2. 선택된 프레임 강조 표시

---

### Step 3: AI에게 구현 요청 (1분)
```
[Cursor AI로 전환]
"이제 Cursor AI를 통해 Figma MCP를 사용하여
선택한 디자인을 코드로 변환하겠습니다."
```

**액션**:
1. Cursor AI 채팅창 열기
2. 다음 메시지 입력:
   ```
   "선택한 페이지를 구현해줘 새로운 html파일을 만들어서 작업해줘"
   ```
3. AI 응답 대기 (약 30초)

**설명**:
```
"AI가 Figma 디자인을 분석하고,
프로젝트 표준에 맞는 HTML과 CSS를 자동으로 생성합니다.
약 30초 정도 소요됩니다."
```

---

### Step 4: 생성된 코드 확인 (1분)
```
[생성된 파일 확인]
"코드가 생성되었습니다. 확인해보겠습니다."
```

**액션**:
1. 생성된 HTML 파일 열기
2. 주요 구조 설명:
   ```html
   - #wrap, #header, #content 구조
   - 프로젝트 표준 준수 확인
   - BEM 네이밍 패턴 확인
   ```
3. CSS 파일 확인:
   ```css
   - 스타일링 확인
   - 반응형 코드 확인
   ```

**설명**:
```
"보시는 것처럼 프로젝트 표준에 맞는 구조로
자동 생성되었습니다. 헤더, 컨텐츠 영역, 
반응형 스타일까지 모두 포함되어 있습니다."
```

---

### Step 5: 수정 요청 (1분)
```
"이미지 경로가 Figma 서버 경로로 되어 있네요.
로컬 경로로 변경하겠습니다."
```

**액션**:
1. Cursor AI에 수정 요청:
   ```
   "이미지 경로를 로컬 경로로 변경해줘"
   ```
2. 수정된 코드 확인

**설명**:
```
"AI가 즉시 이미지 경로를 수정했습니다.
이런 반복적인 작업도 자동화할 수 있습니다."
```

---

### Step 6: 결과 확인 (1분)
```
[브라우저에서 페이지 확인]
"이제 브라우저에서 결과를 확인해보겠습니다."
```

**액션**:
1. HTML 파일을 브라우저에서 열기
2. 디자인 일치도 확인
3. 반응형 동작 확인

**설명**:
```
"디자인과 거의 일치하는 페이지가 생성되었습니다.
전체 작업 시간은 약 3분 정도 소요되었습니다.
기존 방식으로는 약 1시간이 걸렸을 작업입니다."
```

---

## 🎬 시나리오 2: 인터랙션 추가 (5분)

### Step 1: 기존 페이지 확인 (30초)
```
"이제 동적 기능을 추가하는 과정을 보여드리겠습니다.
캐릭터 만들기 중 페이지에 텍스트가 3초마다
변경되는 인터랙션을 추가하겠습니다."
```

**액션**:
1. `creatingCharacter.html` 파일 열기
2. 현재 상태 확인

---

### Step 2: 인터랙션 요청 (1분)
```
[Cursor AI로 전환]
"AI에게 인터랙션 추가를 요청하겠습니다."
```

**액션**:
1. Cursor AI에 요청:
   ```
   "텍스트 부분이 3초마다 바뀌는 인터랙션을 주려고해"
   ```
2. AI 응답 대기

**설명**:
```
"AI가 JavaScript 코드를 생성하여
텍스트 변경 애니메이션을 구현합니다."
```

---

### Step 3: 생성된 코드 확인 (1분)
```
[생성된 JavaScript 코드 확인]
```

**액션**:
1. 생성된 JavaScript 코드 확인:
   ```javascript
   - 텍스트 배열
   - setInterval 함수
   - 페이드 애니메이션
   ```
2. 코드 설명

**설명**:
```
"3초마다 텍스트가 변경되고,
페이드 애니메이션이 적용된 코드가 생성되었습니다.
이런 인터랙션도 빠르게 구현할 수 있습니다."
```

---

### Step 4: 결과 확인 (2분)
```
[브라우저에서 동작 확인]
```

**액션**:
1. 브라우저에서 페이지 열기
2. 텍스트 변경 애니메이션 확인
3. 개발자 도구로 동작 확인

**설명**:
```
"텍스트가 3초마다 부드럽게 변경되는 것을
확인할 수 있습니다. 전체 작업 시간은 약 2분입니다."
```

## 🎬 시나리오 3: 빠른 수정 (5분)

### Step 1: 문제 발견 (30초)
```
"실제 작업 중 발생하는 문제를 해결하는 과정을 보여드리겠습니다.
'하단 영역이 없는 것처럼 보인다'는 피드백을 받았습니다."
```

**액션**:
1. 문제가 있는 페이지 확인
2. 문제 상황 설명

---

### Step 2: 수정 요청 (1분)
```
[Cursor AI로 전환]
"AI에게 문제를 설명하고 수정을 요청하겠습니다."
```

**액션**:
1. Cursor AI에 요청:
   ```
   "캐릭터 생성 페이지는 왜 하단 영역이 없는것처럼 나올까??"
   ```
2. AI 분석 및 수정 제안 확인

**설명**:
```
"AI가 문제를 분석하고 해결 방법을 제시합니다.
CSS에 padding-bottom을 추가하면 된다고 제안했습니다."
```

---

### Step 3: 수정 적용 (1분)
```
[수정된 코드 확인]
```

**액션**:
1. 수정된 CSS 확인
2. 변경 사항 설명:
   ```css
   padding-bottom: 40px; 추가
   ```

**설명**:
```
"즉시 수정이 적용되었습니다.
이런 피드백 반영도 매우 빠르게 처리할 수 있습니다."
```

---

### Step 4: 결과 확인 (2분)
```
[브라우저에서 수정 결과 확인]
```

**액션**:
1. 브라우저에서 페이지 확인
2. 하단 여백 확인
3. 수정 전후 비교

**설명**:
```
"하단 여백이 추가되어 콘텐츠가 화면 하단에
붙지 않게 되었습니다. 수정 시간은 약 1분입니다.
기존 방식으로는 파일을 찾고 수정하는데
5-10분이 걸렸을 작업입니다."
```
