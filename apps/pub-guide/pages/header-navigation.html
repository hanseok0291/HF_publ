Header · Navigation

전역 상단 바 Gnb-header와 서브 화면 상단 Navigation-top(NavigationTop) 스펙 요약입니다. 최신 수치·에셋은 Figma 인스턴스를 우선하고, Cursor 룰 30-design-guide-header-navigation.mdc와 동일 계열입니다.

Gnb-header

앱·서비스 최상단 GNB. 하단 탭(Navigation-bottom)과 역할을 구분합니다.

GNB 정의 (Figma 설명)

  • Home: RROUND 홈 (라이프)
  • Sub: 스토어 / 피드 / 챌린지 / 휘슬 / 페이 / 마이(통합)
Gnb-header Type 변형
Type 좌측 우측
헥토파이낸셜 브랜드 로고 (약 121×18 대역) 액션 아이콘 슬롯
영업CRM 텍스트 타이틀 (예: 타이틀) 동일

레이아웃·토큰

  • 높이 56px, 폭 기준 375
  • 좌우 패딩 16 (spacing-16)
  • 배경 background-01, 하단 구분선 0.5px — 색은 line-* 시맨틱에 맞출 것
  • 우측 아이콘 간격 16px — CSS는 flex gap 대신 margin으로 구현 (20-style-convention)
  • 영업CRM 타이틀: Headline 2 / Bold — 18px, lh 1.4, letter-spacing -3%, weight 700
  • 아이콘 시각 24×24, 단독 버튼 히트 48×48 권장

마크업: <header> 또는 role="banner", 로고·아이콘 버튼 aria-label 등 10-a11y-semantic 참고.

Navigation-top (NavigationTop)

Depth 2·Sub 등 하위 화면 상단 56px 바. Gnb-header와 동시에 이중으로 쌓지 않도록 맥락을 맞춥니다.

NavigationTop property1 변형
property1 구성
Top1_Default_Icon 좌 뒤로 · 중앙 타이틀 · 우 (선택) 보조 텍스트 + 검색 아이콘
Top2_Default_Txt 좌 뒤로 · 중앙 타이틀 · 우 텍스트 액션만
Top3_NonText 좌 뒤로 · 타이틀 없음 · 우 검색 아이콘
Top4_Search 좌 뒤로 · 캡슐 검색 필드(placeholder + 필드 내 검색 아이콘)

공통

  • 높이 56px, 폭 375, 배경 background-01
  • 좌측 ico / allow_left (또는 구현 시 arrow-left 등 정규화 이름) 24×24, 슬롯 left 16 · 너비 64px 대역
  • Top1·Top2 행 내부 간격 8px, 우측 액션 그룹 16px — 역시 margin으로 맞출 것

타이포

  • 중앙 타이틀: Body 1 · Bold 16px, lh 1.4, -2%, text-03, 가운데, 한 줄 말줄임 · 중앙 영역 좌우 padding 72px 대역
  • 우측 보조 텍스트: Body 1 · Regular 16px, text-04

Top4_Search

  • 바 패딩: 세로 6px, 가로 16px
  • 뒤로와 검색 영역 사이 16px
  • 검색 박스: 높이 44px, background-02, 캡슐형 radius — DS 토큰 합의
  • 내부 패딩 가로 16 · 세로 8, 플레이스홀더 text-06 (Body 1 Regular)

하단 탭·Tabs-Bar·시트와의 조합은 30-design-guide-patterns.mdc Navigation 절을 참고합니다.
